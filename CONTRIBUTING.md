# Contributing to Keepsake

Thank you for your interest in Keepsake.

Keepsake's source code is visible under the Functional Source License 1.1 (see `LICENSE.md`), and its signed builds are sold. To keep the right to license and sell the whole of Keepsake, **pull requests from outside contributors are not merged until a contributor licence agreement (CLA) is in place.** Until then:

- **Bug reports and feature ideas are welcome** as GitHub issues. Copy the diagnostic report (Tools → Help → Copy diagnostic report) into the issue.
- Please do not send code, patches or pull requests. They cannot be accepted yet, and reading them could make it harder to write the same change independently.
